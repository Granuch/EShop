## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

`API_BASE_URL` (server-only, default `http://localhost:7000`) is the API gateway that `lib/api.ts` calls.

`TRUST_PROXY_HEADERS=true` forwards the visitor's address to the gateway (the rightmost `X-Forwarded-For` entry), so
rate limits and sign-in throttling apply per visitor rather than to the whole app. Set it only when a reverse proxy in
front of Next sets `X-Forwarded-For` and Next cannot be reached around it: without such a proxy, a browser could send
its own header and choose its bucket. Unset, every visitor shares the Next server's address.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
